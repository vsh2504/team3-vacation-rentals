# Backend — Week 1

FastAPI + Pydantic + SQLAlchemy (production) with a pure-Python domain layer
(`app/domain.py`) that Week 1 tests run without any installed dependency.

Run domain tests: `python3 backend/tests/test_week1.py -v` (from repo root).
Run API (Sprint 1, after deps install): `cd backend && uvicorn app.main:app --reload`
