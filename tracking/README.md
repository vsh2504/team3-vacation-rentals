# Tracker — Jira-like, in repo (CSV) + Excel workbook (Week 1 report)

CSV files here are the repo copy (pushable via the GitHub connector,
which is UTF-8 only). The Excel workbook delivered with the Week 1 report
is the same data with formatting, filters, and frozen panes — use Excel
for meetings, CSV for Git history.

Files:
- backlog.csv — Product Backlog (US01-US28, owner, points, acceptance)
- sprint-backlog-week1.csv — Week 1 Sprint Backlog (status, PR, working day)
- burndown.csv — Planned burndown (119 pts total, Fri/Sat checkpoints)
- blockers.csv — Week 1 blockers, workaround, resolution
- scrum-week1.csv — Week 1 Did / Next / Blocked per agent per working day

Status values: Todo / In Progress / In Review / Done.
Jira-like keys: STAY-1, STAY-2, ... mapped to US IDs in backlog.csv.
